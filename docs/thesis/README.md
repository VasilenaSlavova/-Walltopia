# Дипломна работа — ОКС „Бакалавър“

Дипломант: Василена Славова. Научен ръководител: ас. Георги Георгиев. ТУ–София, ФКСТ, 2026.

Тема: уеб система за предварително определяне на товарите от изкуствени катерачни
съоръжения върху носещата конструкция на сградата (кодовата база в това хранилище:
`server/`, `website/`). Хранилището съдържа и отделно мобилно приложение (`mobile/`),
извън обхвата на тази работа — то изостава от уеб приложението по функционалност (вж.
Заключение, „Насоки за по-нататъшна работа“).

## Компилация

```bash
cd docs/thesis && latexmk -pdf Main.tex
```

Изходът е `build/Main.pdf`. Двигателят е **pdfLaTeX**, не XeLaTeX (T2A + `tempora`);
причината е в `REQUIREMENTS.md`, Б.0.

## Структура

| Файл | Съдържание |
|---|---|
| `Main.tex` | скелет: заглавна страница, ред на разделите |
| `preamble.tex` | форматиране по изискванията на ФКСТ; всяка секция сочи правило от `REQUIREMENTS.md` |
| `REQUIREMENTS.md` | нормативните изисквания (Част А) и преводът им към LaTeX (Част Б) |
| `chapters/` | съдържанието по раздели |
| `references.bib` | литературни източници |
| `latexmkrc` | настройки на компилацията |

## Какво остава да се попълни

```bash
grep -rn 'TODO' chapters/ Main.tex
```

Към момента остават само двата физически подвързани документа (утвърденото дипломно
задание и декларацията за авторство, вж. `Main.tex`) — те се добавят като сканирани
страници непосредствено преди печат. Всичко останало е попълнено.

## Бележка за `latexmkrc`

BibTeX се изпълнява вътре в `build/` и не вижда `references.bib` в папката на източника.
На MiKTeX това не поражда грешка: kpathsea намира **чужд** файл със същото име от дървото
на дистрибуцията и произвежда празен списък с литература. Затова `latexmkrc` подава
папката на източника изрично. Не махай този ред.
